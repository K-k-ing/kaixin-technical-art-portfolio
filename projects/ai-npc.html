Overview

This project is an Unreal Engine interaction prototype that connects proximity-based player interaction, dialogue UI, continuous conversation history, and a third-party AI API.

Core Features

  • Proximity detection
  • Press E interaction prompt
  • Dialogue interface
  • Text input and message submission
  • Continuous conversation history
  • Third-party AI API integration
  • Player input control during dialogue
  • Gameplay control restoration after closing the interface

Interaction State Flow

The prototype explicitly hands control between gameplay, the dialogue interface, API messaging, and the restored player state.

  1. 01

    Player Enters Range

    Proximity detection confirms that the NPC can be used.

  2. 02

    Interaction Prompt Appears

    The interface presents a contextual Press E prompt.

  3. 03

    Player Presses E

    The interaction input starts the dialogue state.

  4. 04

    Dialogue UI Opens

    The conversation interface becomes visible over the scene.

  5. 05

    Gameplay Input Is Disabled

    Movement input pauses while the player uses the dialogue controls.

  6. 06

    Message Is Submitted

    The current player text is sent through the conversation system.

  7. 07

    AI Response Is Displayed

    The returned response is added to the visible conversation history.

  8. 08

    UI Closes

    The dialogue interface is dismissed by the player.

  9. 09

    Gameplay Input Is Restored

    Movement and camera control return to the gameplay state.

System Components

Each component has a focused responsibility within the interaction loop.

Proximity Detection

Tracks whether the player is inside the NPC's usable interaction range.

Interaction Prompt

Communicates when the player can begin a conversation.

Dialogue Interface

Provides the visual container for messages, controls, and conversation context.

Text Input and Submission

Collects the player's message and passes it into the conversation request.

Conversation History

Keeps previous player and NPC messages visible across the active exchange.

Third-Party AI API

Receives submitted text and returns the NPC response used by the interface.

Player Input Control

Disables gameplay movement while the dialogue interface is active.

Interface Closing and State Restoration

Closes the conversation view and returns control to the player.

Limitations

The prototype validates the interaction loop but does not claim production-ready service architecture.

  • Prototype-level error handling
  • Limited conversation memory
  • No production authentication system
  • No offline fallback
