项目概述

这是一项自主发起的技术美术研发项目，探索如何根据游戏资产的几何与材质属性，建立可复用的初始风化数据生成流程。管线在 Blender 中生成 UV 空间的磨损、锈蚀与污垢遮罩，再用这些遮罩驱动 Unreal Engine 5 中可调节的实时风化效果。

AI 用于上游资产开发；当前风化系统本身基于可解释的几何分析、导出的遮罩与美术可控的材质参数。

问题

在使用 AI 辅助生成的三维资产时，我发现模型进入实时引擎前仍需要大量手工材质处理。表面磨损、氧化与污垢经常需要重复绘制，也难以在多个资产之间一致地调整最终效果。

研究问题

如何从资产自身生成可复用的首轮风化分布，同时让最终外观在游戏引擎中保持可编辑？

设计目标

  • 从网格数据生成可复用的首轮风化遮罩
  • 让输出结果可在 Substance、Blender 或实时引擎中继续编辑
  • 允许美术调整风化强度，无需重新生成纹理
  • 建立透明、可解释的管线，使处理过程便于检查

管线概览

工作流将几何分析、UV 空间数据生成与最终外观制作分开，使每个阶段都能独立检查和调整。

  1. 01

    游戏资产

    以现有网格和材质组作为研究的源数据。

  2. 02

    网格与 UV 验证

    当前版本会检查资产是否已有可用网格与 UV 贴图坐标。

  3. 03

    几何与材质分析

    评估曲率、法线变化、金属区域、环境光遮蔽（AO）与凹陷信号。

  4. 04

    UV 空间遮罩生成

    在 UV 三角形中插值顶点权重，生成灰度遮罩。

  5. 05

    PNG 导出

    将 WearMask、RustMask 与 DirtMask 导出为可复用的纹理数据。

  6. 06

    UE5 主材质

    导出的遮罩在 M_AI_Weathering 中驱动表面混合。

  7. 07

    实时控制

    通过材质实例参数调整磨损、锈蚀与污垢，无需替换网格。

Blender Python 管线

Blender 阶段根据可测量的网格信号生成初始分布，目前不进行环境语义推断。

01 / 磨损

磨损遮罩

根据曲率与法线变化，识别暴露边缘和结构转折。

02 / 锈蚀

锈蚀遮罩

结合金属区域信息、AO 与凹陷信号，将氧化分布限制在合理的金属及遮蔽区域。

03 / 污垢

污垢遮罩

使用 AO 与凹陷信息，识别凹槽、连接处及局部遮蔽区域。

UV 空间生成

将分析数值转化为通用纹理数据，便于在分析脚本之外检查与细化。

01

插值

在每个 UV 三角形内部插值顶点分析权重。

02

光栅化

在 0–1 UV 区域内，将各类信号写入灰度遮罩。

03

边缘扩展

通过可配置的边缘填充与膨胀，将像素值延伸到 UV 岛边界之外。

边缘扩展可减少 UV 岛周围的采样瑕疵，但复杂镜像、重叠 UV 与跨岛连续性仍有待完善。当前版本需要已有有效 UV，不包含自动展 UV 或 UDIM 支持。

Unreal Engine 材质系统

通过材质实例控制，将可复用遮罩转化为可无损调整的表面状态。

UE5 材质让风化结果保持可无损调整。同一个网格与主材质，通过改变实例参数即可产生多种资产状态，无需替换整套纹理。

挑战与技术决策

各项决策围绕可用的初步结果展开，同时保留美术控制权，并记录当前局限。

01

UV 岛边界与采样瑕疵

处理方式： 使用可配置的边缘填充与膨胀，同时明确记录仍然存在的接缝局限。

02

程序化遮罩在技术上合理，但视觉上可能过于均匀

处理方式： 分离磨损、锈蚀与污垢信号，让美术能够独立调整或重绘。

03

烘焙后的最终纹理不便在引擎中迭代

处理方式： 将生成的遮罩作为可复用数据，在 UE5 主材质中完成最终混合。

局限与后续计划

当前版本已验证核心流程。以下分别列出当前局限与计划中的改进，后续计划尚未实现。

当前局限

  • 需要已有可用网格与 UV 坐标
  • UV 岛边界仍可能出现接缝与采样瑕疵
  • 不支持自动展 UV
  • 不支持 UDIM
  • 目前仅在一个硬表面头盔资产上验证
  • 尚无批处理或预设系统

后续计划

  • 为无 UV 的资产自动展开 UV
  • 批量处理资产
  • 保存与加载预设
  • Substance Painter 导出预设
  • RGB 通道打包遮罩导出
  • 针对不同材质的风化配置
  • 结合环境语义的风化分布
  • 可选的 AI 辅助细化

AI 辅助细化属于未来研究方向，目前尚未部署推理系统。

我的贡献

我独立确定技术方向，实现并验证 Blender 遮罩生成流程，搭建 UE5 材质逻辑，在 AI 朝圣者头部资产上测试系统，录制演示并整理完整工作流文档。

核心收获

这个项目改变了我对 AI 辅助资产制作的理解。生成资产只是起点；更大的技术美术挑战，是构建可控、可复用、可解释的系统，让生成内容能够进入实际游戏制作流程。
