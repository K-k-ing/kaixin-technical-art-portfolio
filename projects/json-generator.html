JSON-Driven Procedural Environment Generator for UE5

A Blueprint-based procedural tool that converts structured JSON data into configurable real-time environments.

Type
Independent Project
Engine

Tools

Year

Overview

This project explores how structured JSON data can be translated into modular Unreal Engine environments. The tool reads environment parameters and automatically rebuilds the scene through a Blueprint Construction Script, allowing designers to adjust layouts without manually repositioning every asset.

Problem

Building multiple environment variations manually requires repeated placement, scaling, alignment, and parameter adjustment. This slows down iteration and makes it difficult to test different room configurations efficiently.

Solution

I created a Blueprint-based generator that maps JSON parameters to Unreal Engine variables and modular mesh slots. When values are updated, the Construction Script automatically regenerates the environment.

Core Features

  • Configurable room width and length
  • Adjustable wall height and tile size
  • Custom cabinet and light counts
  • Randomized prop placement
  • Modular mesh assignment
  • Automatic Construction Script refresh
  • JSON-driven parameter mapping
  • Rapid layout iteration

System Architecture

The internal logic translates structured scene data into artist-editable controls and a validated modular environment.

  1. 01

    JSON Input

    Structured environment parameters define room dimensions, asset counts, and generation settings.

  2. 02

    Parameter Mapping

    JSON values are translated into exposed Blueprint variables.

  3. 03

    Blueprint Variables

    Design parameters remain artist-facing and editable inside Unreal Engine.

  4. 04

    Construction Script

    The scene rebuilds automatically when values are updated.

  5. 05

    Modular Mesh Assignment

    Predefined mesh slots are used for floors, walls, cabinets, lights, tables, and props.

  6. 06

    Scene Generation

    The tool assembles the room and places modular assets based on the selected parameters.

  7. 07

    Editor Validation

    The generated layout is reviewed directly in Unreal Engine for scale, placement, and usability.

Workflow

The production sequence moves from visual reference to structured data, tool setup, and editor testing.

  1. Reference Image

    Establish the intended room layout, atmosphere, and spatial hierarchy.

  2. Visual Breakdown

    Identify room zones, repeatable modules, and assets that need exposed controls.

  3. Structured JSON

    Organize dimensions, asset counts, and generation settings as readable input data.

  4. Blueprint Variable Mapping

    Connect input values to editable variables inside the generator Blueprint.

  5. Modular Mesh Assignment

    Assign reusable environment assets to the appropriate exposed mesh slots.

  6. Construction Script Generation

    Rebuild the environment in the editor whenever the configuration changes.

  7. Unreal Engine Validation

    Review scale, circulation, placement, and modular fit in the final scene.

Each stage is documented with the source data, configurable parameters, modular setup, and validated scene output.

Limitations

The current version is designed for rectangular interior environments and relies on predefined modular mesh slots. Future development could include nested JSON structures, editor utility widgets, collision-aware placement, procedural rule systems, and runtime generation.
