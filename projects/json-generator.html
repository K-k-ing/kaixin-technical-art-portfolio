项目概述

本项目探索如何将结构化 JSON 数据转化为 Unreal Engine 模块化场景。工具读取场景参数，通过蓝图构造脚本自动重建场景，使设计人员无需逐个手动移动资产即可调整布局。

问题

手工制作多个场景变体，需要反复摆放、缩放、对齐和调整参数。这会拖慢迭代，也不便于高效测试不同的房间配置。

解决方案

我创建了基于蓝图的生成器，将 JSON 参数映射到 Unreal Engine 变量与模块化网格插槽。参数更新后，构造脚本会自动重新生成场景。

核心功能

  • 可配置房间宽度与长度
  • 可调整墙高与地砖尺寸
  • 可自定义柜体与灯光数量
  • 随机摆放道具
  • 模块化网格分配
  • 构造脚本自动刷新
  • JSON 驱动的参数映射
  • 快速迭代布局

系统架构

系统将结构化场景数据转化为美术可编辑的参数，并生成经过验证的模块化场景。

  1. 01

    JSON 输入

    用结构化场景参数定义房间尺寸、资产数量与生成设置。

  2. 02

    参数映射

    将 JSON 数值转换为对外开放的蓝图变量。

  3. 03

    蓝图变量

    设计参数在 Unreal Engine 中保持可见、可编辑，方便美术使用。

  4. 04

    构造脚本

    参数更新后自动重建场景。

  5. 05

    模块化网格分配

    为地板、墙体、柜体、灯光、桌子与道具提供预定义网格插槽。

  6. 06

    场景生成

    根据选定参数组装房间并放置模块化资产。

  7. 07

    编辑器验证

    直接在 Unreal Engine 中检查生成布局的尺度、摆放与可用性。

工作流程

制作流程从视觉参考出发，经过结构化数据整理、工具配置与编辑器测试。

  1. 参考图像

    确定目标房间布局、氛围与空间层级。

  2. 视觉拆解

    识别房间分区、重复模块与需要开放控制参数的资产。

  3. 结构化 JSON

    将尺寸、资产数量与生成设置整理为可读的输入数据。

  4. 蓝图变量映射

    将输入值连接到生成器蓝图中的可编辑变量。

  5. 模块化网格分配

    将可复用场景资产分配到对应的开放网格插槽。

  6. 构造脚本生成

    配置变化时，在编辑器内重建场景。

  7. Unreal Engine 验证

    检查最终场景的尺度、动线、摆放与模块衔接。
